This is the repository for Johan Kou and Connor Vallero's improved real-time inference speed implementation of a multi-camera people tracking machine learning pipeline. This project is based on the 2024 AI City Challenge Track 1 Winning team, Xie et al. and their paper on their project titled "A Robust Online Multi-Camera People Tracking System With Geometric Consistency and State-aware Re-ID Correction".
Notable changes that we've made to their implementation include combining person detection and pose estimation models into the combined RTMO model, created by [Lu et al.](https://arxiv.org/pdf/2312.07526). We also experimented with swapping out the MGN-R101 re-identification model that the authors used for less computationally intensive models.
MGN-R101 performs both global and local feature extraction to enable the recognition of the same person across time in a video, and we swapped it out for models from the fast-reid model zoo that only used global feature extraction.
